# Assemblyreel.io - AI Video Generation SaaS

Welcome to the central Knowledge Vault (Map of Content). This project is an automated personal content engine that generates highly tailored video drafts for niche social media channels using a multi-agent AI pipeline and a React-based programmatic video rendering engine (Remotion).

## Core Architecture Pillars

Navigate through the numbered pillars below to understand every facet of this system:

1. **[[01_PROJECT_PLAN]]**: The current roadmap, phases, and milestone tracking.
2. **[[02_ARCHITECTURE]]**: The core tech stack (Next.js, Supabase) and strict directory layout.
3. **[[03_AI_PIPELINE]]**: Deep dive into the 7-Agent generative logic (Script Writer, Slicer, Casting, etc.).
4. **[[04_REMOTION_ENGINE]]**: The programmatic video compiler and Dynamic Motion Graphic capabilities.
5. **[[05_DATABASE_SCHEMA]]**: The Supabase relational database schema and tables.
6. **[[06_API_INTEGRATIONS]]**: Third-party services powering the media (Fal.ai, Cartesia, ElevenLabs, Stripe).
